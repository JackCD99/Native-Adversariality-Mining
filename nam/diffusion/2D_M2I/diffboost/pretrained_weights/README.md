# DiffBoost initialization weights

Place the licensed RadImageNet-pretrained ControlNet initialization at:

```text
pretrained_weights/radimagenet/model.ckpt
```

The official DiffBoost README previously linked this checkpoint, but the link
was withdrawn due to RadImageNet data requirements. Obtain it from the authors
or migrate a legally held checkpoint. Do not substitute a random checkpoint
without the required upstream weights. See `../README.md` for the complete workflow.
